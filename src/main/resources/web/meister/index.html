Benachrichtigung

helden.jar

Prüfung und Austausch macht der eingebaute Updater der helden.jar. Der Server startet ihn nur einmal täglich zu dieser Uhrzeit.

Speicherorte im Container

Alles unter /data liegt auf Unraid-Volumes und bleibt bei Container-Updates erhalten.

/data/audio/Music/<Szene>Musik (Village, Travel, Dungeon, Castle, Fight)
/data/audio/Sounds/<Szene>Hintergrundgeräusche
/data/audio/EffectsEffekt-Knöpfe (Schatztruhe.mp3, Kuh.mp3 …)
/data/audio/…Upload über „Dateiordner“ im Soundboard oder per FTP
/data/heldenHelden-XML, per FTP befüllbar
/data/db/heldenhort.sqliteEinstellungen, Sessions, Freigaben
/data/jar/helden.jarersetzt sich selbst über ihren Updater
